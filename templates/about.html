About This Project

Bank Statement Analyzer is a web application that helps users upload bank statements and analyze their financial transactions.

  • HTML

Project Features

  • Expense and Income Analysis
  • Interactive Dashboard and Charts
  • ML-Based Transaction Categorization
  • Transaction Search and Filtering
  • CSV Report Download
